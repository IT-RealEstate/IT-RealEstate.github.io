# טביב שמאות — גרסת בטא לבדיקה

עותק סקירה של האתר, לבדיקה חזותית במכשירים אמיתיים. **זו אינה גרסת ייצור.**

## מה שונה מגרסת הייצור

- **שמירת פרטים מהטופס מושבתת.** `assets/js/intake-config.js` מגיע עם
  `endpointUrl` ריק. `intake.js` בודק את הערך הזה בתחילת `attemptPersist()`
  ויוצא לפני כל בקשת רשת — שום דבר שמבקר מקליד ב-`/check/` אינו יוצא
  מהדפדפן שלו.
- **בלוק הפרטיות ב-`/check/` נכתב מחדש לגרסה הזו.** נוסח הייצור מתאר
  עיבוד שאינו מתרחש כאן (שמירה ב-Google, המשך ב-WhatsApp) ומבקש אישור
  למדיניות שאינה מפורסמת בבנייה הזו. הצהרה שאינה נכונה גרועה מהיעדר
  הצהרה, ולכן נשאר רק מה שנכון. גרסת הייצור שומרת את הנוסח המאושר כלשונו.
- **עמוד `/legal/` אינו כלול,** וגם לא הקישורים אליו.
- **כל העמודים `noindex, nofollow`,** ו-`robots.txt` חוסם סריקה במלואה.
- **אין `sitemap.xml`;** תגיות `canonical` ו-`og:url` הוסרו — הן הצביעו על
  דומיין שטרם נקבע.
- **הערות HTML ו-CSS פנימיות הוסרו** מהבנייה הציבורית.

## לפני השקה אמיתית

יש להשלים שבעה ערכים משפטיים (שם משפטי, ח״פ/עוסק, כתובת, דומיין, ספק
אחסון, סוג חשבון Google, אזורי שירות), לפרסם את `/legal/` ולהחזיר את
הקישורים אליו, לחבר יעד שמירה לטופס, ולהסיר את חסימת האינדוקס.

## מבנה

`/` · `/damage/` · `/check/` — HTML סטטי בלבד. אין תלויות, אין שלב build,
אין בקשות לצד שלישי. הגופנים מאוחסנים מקומית (IBM Plex Sans Hebrew,
רישיון OFL — ראו `assets/fonts/`).
